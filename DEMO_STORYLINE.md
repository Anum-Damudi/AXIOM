# AXIOM — Demo Storyline
Maintained by Member 6 (Data, Testing & Product Lead)

## Goal
Show judges how NEXUS-CRIME turns scattered case data into a clear, connected picture — in under 5 minutes.

## Demo Flow

### 1. The Setup (30 sec)
- Investigator has a new case: multiple people, a vehicle, a location, all mentioned in a messy text report.
- Show the raw case report text on screen (from case_reports.json).

### 2. Upload / Input (30 sec)
- Upload or paste the case report into the system.
- AI (NLP module) extracts entities: people, vehicle, location, date.

### 3. Graph Builds Automatically (1 min)
- Show the knowledge graph updating live — new nodes and connections appear.
- Point out: "The system found this connection automatically, without manual work."

### 4. Key Insights (1.5 min)
- Highlight the "central figure" the system identifies (most connected person).
- Show a hidden/indirect link between two people who never directly interacted.
- Show community/cluster detection — "these 4 people form a group."

### 5. Evidence Panel (30 sec)
- Show an uploaded crime-scene image linked to the case.
- Point out any detected objects/text from the image.

### 6. Wrap-up (30 sec)
- Recap: "What used to take an investigator hours of manual cross-referencing now happens in seconds."
- Mention responsible AI: "AI suggests leads, evidence supports them, investigators decide."
